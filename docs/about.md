# About

Autodiscover Email Settings is maintained by [Freifunk München](https://ffmuc.net/) at [freifunkMUC/autodiscover-email-settings](https://github.com/freifunkMUC/autodiscover-email-settings). Issues and pull requests are welcome there.

It continues [Monogramm/autodiscover-email-settings](https://github.com/Monogramm/autodiscover-email-settings), which was inspired by [sylvaindumont/autodiscover.xml](https://github.com/sylvaindumont/autodiscover.xml), [johansmitsnl/docker-email-autodiscover](https://github.com/johansmitsnl/docker-email-autodiscover) and [Tiliq/autodiscover.xml](https://github.com/Tiliq/autodiscover.xml). Thanks to [@HLFH](https://github.com/HLFH) for the original nginx and systemd examples.

It is distributed under the [MIT License](https://github.com/freifunkMUC/autodiscover-email-settings/blob/master/LICENSE).

## Specifications

- Autoconfig: [draft-ietf-mailmaint-autoconfig](https://datatracker.ietf.org/doc/draft-ietf-mailmaint-autoconfig/)
- Autodiscover: [MS-OXDSCLI](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxdscli/78530279-d042-4eb0-a1f4-03b18143cd19)
- ActiveSync Autodiscover: [MS-ASCMD](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-ascmd/1a3490f1-afe1-418a-aa92-6f630036d65a)
- Configuration profiles: [apple/device-management](https://github.com/apple/device-management)
- Mail server SRV records: [RFC 6186](https://www.rfc-editor.org/rfc/rfc6186)
